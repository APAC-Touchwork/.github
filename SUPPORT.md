## Before Opening an Issue

To avoid duplicate issues, please:

1. **Search existing issues** — Check [open issues](https://github.com/APAC-Touchwork/.github/issues) and [closed issues](https://github.com/APAC-Touchwork/.github/issues?q=is%3Aissue+is%3Aclosed) to see if your question or problem has already been addressed.
2. **Check the documentation** — Review the repository's README and any linked documentation first.
3. **Search Discussions** — Your question may already have been answered in [GitHub Discussions](https://github.com/APAC-Touchwork/.github/discussions).

## Opening an Issue

If you've searched and haven't found an answer, open a new issue using one of our templates:

- 🐛 **Bug Report** — Something isn't working as expected
- ✨ **Feature Request** — You'd like to suggest an improvement
- 📋 **General Issue / Task** — Everything else

## Contributing

If you'd like to fix a bug or contribute a feature yourself, please read our [Contributing Guide](./CONTRIBUTING.md) first.
